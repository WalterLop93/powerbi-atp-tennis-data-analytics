# ATP Tennis Data Analytics

Business Intelligence and Data Analytics project focused on ATP professional tennis tournaments between 2000–2024.

Developed using Power BI, Power Query and DAX measures to analyze tournaments, rankings, players and match statistics.

---

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
- Data Modeling
- Business Intelligence

---

## Main KPIs

- Total tournaments
- Total matches
- Total players
- Ranking analysis
- Match trends
- Lower-ranked player victories

---

## Dataset Source

Dataset obtained from Kaggle:
ATP Tennis 2000–2024 Daily Update

---

## Project Structure

- `/data` → datasets
- `/documentation` → project documentation
- `/images` → dashboard screenshots
